# 🏏 IPL Cricket Performance Analysis

## 📌 Project Overview

This project focuses on analyzing IPL ball-by-ball cricket data to understand player and team performance using Python, Pandas, and Matplotlib.

The analysis explores batting performance, bowling performance, team scoring patterns, and player efficiency through statistical analysis and data visualization.

---

## 🎯 Objectives

- Analyze IPL cricket performance using ball-by-ball data
- Identify the top run-scoring batsmen
- Identify the leading wicket-taking bowlers
- Compare total runs scored by different IPL teams
- Analyze batting efficiency using Strike Rate
- Analyze bowling efficiency using Economy Rate
- Present insights through clear and meaningful visualizations

---

## 📊 Analysis Performed

### 🏏 Batting Analysis

- Top 10 run scorers
- Total runs scored by each batsman
- Balls faced by players
- Strike Rate analysis
- Comparison of batting efficiency

### 🎯 Bowling Analysis

- Top 10 wicket-taking bowlers
- Wicket analysis
- Economy Rate analysis
- Comparison of bowling efficiency

### 🏆 Team Analysis

- Team-wise total runs
- Comparison of scoring performance across IPL teams

### 🔍 Data Quality Analysis

- Dataset dimensions
- Data types
- Missing value analysis
- Duplicate record check
- Basic statistical analysis

---

## 📈 Visualizations

The project includes the following visualizations:

1. Top 10 IPL Run Scorers
2. Top 10 IPL Wicket Takers
3. Total Runs by IPL Teams
4. Top 10 Players by Strike Rate
5. Top 10 Bowlers by Economy Rate

These visualizations help identify important patterns and performance differences between players and teams.
